All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-09-22

### Added

- Initial release of `indexedlinkedlist` package
- Core data structure: `IndexedLinkedList` with:
  - `add`, `remove`, `__getitem__`, `__setitem__`, `__len__`
  - `get_first`, `get_last`, `index_of`, `update`
  - Converters: `to_list`, `to_dict`, `to_set`, `to_tuple`
  - Optional strict mode for defensive checks
- Utilities: `invert_dict`
- Project documentation: `README.md`
- Licensing: `LICENSE` (MIT)
- Community files: `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `ISSUE_TEMPLATE.md`
